# Daily Flow

A local-first personal time manager — daily tasks, upcoming events, and
meetings — built as an installable **PWA**. All data lives on the device
(IndexedDB); there is no backend and nothing leaves the phone.

## Stack

- **Vite + React + TypeScript** (strict, no `any`)
- **Dexie** — IndexedDB wrapper, the local-first data layer
- **Tailwind CSS v4** (`@tailwindcss/vite`)
- **vite-plugin-pwa** (`injectManifest`, `autoUpdate`) — manifest + service worker

## Views

- **Today** — tasks dated today (completed ones sink to a "Done" group).
- **Upcoming** — open tasks/events from today on, ranked by a blend of
  priority and date (a high-priority item surfaces a couple of days ahead of
  a low-priority one).
- **Meetings** — open meetings, with time + location shown on each row.

## Features

- **Quick-add** per view, docked under the list. The Meetings form also asks
  for time + location; Upcoming lets you pick a date.
- **Toggle done** by tapping the checkbox.
- **Edit** any field by tapping a row (bottom-sheet editor).
- **Delete** by swiping a row left, or from the editor.
- **Recurring tasks** — completing a `daily`/`weekly` item auto-creates the
  next instance on the next matching date (de-duplicated).
- **Local reminders** — Notification API + service worker for timed items.
  Permission is requested *only* when you switch a reminder on.

  > On iOS, web notifications fire **only** when the app is installed to the
  > Home Screen and running standalone (iOS 16.4+). The bell hint tells you
  > when you need to "Add to Home Screen" first.

- `navigator.storage.persist()` runs at startup to protect data from eviction.

## Develop

```bash
npm install
npm run dev        # local dev server
npm run build      # tsc -b + vite build → dist/  (emits manifest + sw.js)
npm run preview    # serve the production build
```

Placeholder icons are generated by `node scripts/gen-icons.mjs` (no deps).

## Deploy (Netlify)

Fully static — no SSR. Either:

- **Git-based**: point Netlify at the repo; `netlify.toml` sets
  `npm run build` → publish `dist/`.
- **Drag-and-drop**: run `npm run build` and drop the `dist/` folder into
  Netlify.

## Install on iPhone

Open the deployed URL in Safari → Share → **Add to Home Screen**. Launch it
from the Home Screen icon to get standalone mode (and working reminders).
